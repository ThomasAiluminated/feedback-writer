# Voorbeeld: feedback op een betoog, 4e middelbaar

*Example of a full input and output (Dutch). The skill works the same way in English and French.*

## Input

> Geef feedback op dit eerste ontwerp van een betoog (4e jaar, 15–16 jaar). Leerdoel: een standpunt onderbouwen met twee relevante argumenten en een tegenargument weerleggen. Ze herwerken de tekst volgende week.
>
> *[geanonimiseerde tekst van ±400 woorden over de stelling "Smartphones moeten verboden worden op school"]*

## Output

### Feedback voor de leerling

**Wat goed werkt**
- Je standpunt is meteen duidelijk: al in je eerste zin weet de lezer wat je vindt.
- Je eerste argument onderbouw je met een concreet voorbeeld: "tijdens de les wiskunde zag ik drie mensen op TikTok zitten". Daardoor wordt je argument geloofwaardig.

**Om te verbeteren in je volgende versie**
1. **Je tweede argument herhaalt het eerste.** Beide gaan over afleiding in de les (alinea 2 en 3). Zoek een argument vanuit een andere hoek, bijvoorbeeld sociaal contact op de speelplaats of cyberpesten.
2. **Het tegenargument noem je, maar je weerlegt het niet.** In alinea 4 schrijf je: "Sommigen zeggen dat je je gsm nodig hebt in noodgevallen." Daarna ga je meteen verder. Voeg twee of drie zinnen toe die uitleggen waarom dat bezwaar jouw standpunt niet verandert (bv. het secretariaat kan ouders altijd bereiken).
3. **Je slot introduceert een nieuw idee.** "Ook leerkrachten zouden hun gsm moeten wegleggen" is een interessant punt, maar het hoort niet in je besluit. Vat in je slot je twee argumenten samen.

**Begin met:** alinea 4 herschrijven, zodat het tegenargument echt weerlegd wordt.

### Notities voor de leerkracht

- De spelling is op enkele plaatsen zwak (dt-fouten in alinea 2). Ik heb ze weggelaten om de focus op het leerdoel te houden; een aparte taaltaak kan nuttig zijn.
- Ik heb geen cijfer gegeven. Op basis van het leerdoel lijkt deze versie nog niet geslaagd voor de weerlegging, maar dat oordeel ligt bij jou.
